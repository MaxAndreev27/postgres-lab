# Contributing

Thank you for helping improve PostgreSQL Lab.

## Before You Start

1. Search existing issues and pull requests before opening a new one.
2. For larger changes, open an issue first to discuss the approach.
3. Never commit passwords, tokens, private keys, or local database data.

## Development

1. Create a focused branch from `main`.
2. Make the smallest change that solves the problem.
3. Validate the Compose configuration with `docker compose config`.
4. Update the README when setup or behavior changes.
5. Use a clear commit message and open a pull request against `main`.

## Pull Requests

Please describe the problem, the solution, and how you tested it. Keep pull requests focused and be ready to respond to review feedback.
